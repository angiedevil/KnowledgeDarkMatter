# Knowledge Dark Matter

**Reasoning about what is missing.**

Most knowledge systems and AI models treat a missing fact as a blank. But
not all absence is equal. Some gaps leave a detectable trace in the
structure around them. I call these gaps **Knowledge Dark Matter (KDM)**:
gaps whose existence can be inferred from the surrounding structure, even
though the gap itself is never recorded.

I am developing a framework and system for finding these gaps, ranking
which ones matter, and testing them against evidence, with a full audit
trail. This is early-stage work and the central idea is a working
hypothesis that has not yet been validated.
